## 环境要求

- GCC / G++（支持 C++17）
- 无第三方库

## 编译与运行

```bash
g++ -std=c++17 homework/week1/7_1_最大公约数和最小公倍数.cpp -o main
./main
```

C 文件使用 `gcc`：

```bash
gcc path/to/file.c -o main
./main
```
